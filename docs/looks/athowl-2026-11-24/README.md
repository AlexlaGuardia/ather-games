# M102 Athowl base form, look + rig proof (2026-11-24). Nothing in game.
- `sheet.jpg`: front, three-quarter, side, rear, face, the Vulnyx v2 for scale and the phone screen; second row = clips. `sheet-with-ref.jpg` = the same with the locked ref beside it: LOCAL ONLY (gitignored; this repo is public and the ref is not uploaded). `clips.webm`: idle, hop, fly, glide, perch, sleep (three-quarter + side).
- `athowl.glb` (unrigged, 1 unit tall = 0.50 m), `athowl-rigged.glb` (25 bones; nodes `body` + `eyes`), `athowl-metrics.json`.
- Sculpted in code (tools/sculpt.py on the Vulnyx v2 helpers), no outside service, the ref never uploaded. Closed, one island, 0 handles: 6,204 body + 1,310 eye tris (the eye part carries the irises, the forehead mark, the claws and the lids).
- Built for motion: the wings are blades cut free of the body (4 bones each, drawn out about 1.45x when they open: span 0.74 m); the head turns on a neck hidden in a groove under its rim (3 bones share a turn), so the outside never shears; `b_lids` slides two closed lids through the eyes (blink, sleep).
- Clips under the game's names: idle, walk = two-footed hop, run = FLY (feet about 0.12 m up), sit = perch, lie = sleep; plus glide (no game clip yet). Numbers for wiring: h 0.50, clipV walk 0.55/0.50, run 2.8/0.50, runAt about [0.9, 0.75], hull 0.024, neck b_neck, head b_head. Look used: emissive #e7ddff (lavender-silver) 0.10, hull #f3ecff 0.38, gold rim shared.
- `tools/three-check.mts`: three's GLTFLoader + the game's makeRigBody; every blend measured with the game's own ground keep on.
- Rebuild: `python tools/sculpt.py athowl.glb 4000`, `blender -b -P tools/rig.py`, `npx tsx tools/three-check.mts`, `tools/look.py`, `tools/scale.py`, `tools/reel.py` (python = any venv with numpy, trimesh, fast_simplification, scipy).
- Still off the ref: painted feather texture and pearl tints are flat toon colour with a few feather marks; tufts shorter; a flat shoulder line under the head where the ref's chest feathers run up into the chin; toes smaller; breast marks a little ragged. Back, sides and tail are not in the ref (tail = plain short fan).
