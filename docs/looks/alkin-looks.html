Alkin look options

The same Alkin shopkeeper built five ways, from code blockouts like the game's. Drag a figure to turn it. The proportions and shading are what differ; colours and clothes are placeholders.

Head-to-height ratio is the number under each name: 1 : 2 means the head is half the figure. All five use about the same polygon budget as the chibi Moglin, so any of them is fine for phones. Jin's pick is marked.
